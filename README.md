# Artificial Intelligence: From Fundamentals to Advanced Methods

A comprehensive, structured collection of artificial intelligence concepts, algorithms, and practical implementations, covering the mathematical foundations of AI through modern machine learning and deep learning techniques.

The project emphasizes a strong understanding of theoretical principles, mathematical formulations, and algorithmic behavior through hands-on implementations, numerical experiments, and reproducible evaluations.

Core algorithms are implemented from scratch using Python and NumPy, alongside implementations with established frameworks such as PyTorch and Scikit-learn.

## Core Topics

1. **Mathematics for AI:** Linear algebra, calculus, probability, statistics, and numerical optimization.
2. **AI Foundations:** Search algorithms, constraint satisfaction, logic, and classical AI techniques.
3. **Machine Learning:** Supervised and unsupervised learning, dimensionality reduction, and model evaluation.
4. **Deep Learning:** Automatic differentiation, neural networks, optimization, and modern architectures.
5. **Large Language Models:** Tokenization, attention mechanisms, transformers, fine-tuning, and retrieval-augmented generation.
6. **Reinforcement Learning:** Markov decision processes, value-based methods, policy optimization, and alignment techniques.

## Approach

Each topic is developed through a combination of mathematical explanations, modular Python implementations, interactive Jupyter notebooks, and automated tests.

The objective is to bridge the gap between theoretical understanding and practical implementation while maintaining clarity, correctness, and reproducibility.
